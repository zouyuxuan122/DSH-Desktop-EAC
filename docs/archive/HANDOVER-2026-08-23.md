## 1. 项目是什么（30 秒版）

把官方内核封装为开箱即用的桌面端：内置 Node 运行时免装依赖、无边框玻璃栏窗口、托盘常驻、38 个内置配套插件 + 10 款皮肤 + 统一插件市场、插件保护中心、崩溃救援 + AI 修复。**内核零改动**，与原生 CLI 共享 `DSH_HOME`。

```
┌─ L1 桌面集成层（Electron main.js ←→ 正在替换为 Rust/Tauri）
│    窗口 / 托盘 / 对话框 / .lnk / 单实例锁 / IPC ↔ WS 桥
├─ L2 业务服务层 = lib/desktop/* 13 模块（✅ 全部 .ts）+ 根目录 ~28 服务模块
│    未来宿主 = Node sidecar（tauri-shell/sidecar/server.js ✅ 已挂载全部 13 模块）
└─ L3 内核（绝对不动区）：@deepseek-ai/* + Cordis 插件树 + Web UI + assets/plugins|skins
```

## 3. ⚠️ 环境速查（本机特有坑，接手必读）

| 项 | 值 / 坑 |
| --- | --- |
| Node/npm | v24.11.1 @ `D:\nodejs`；npm ci 可用 |
| **Rust/Cargo** | 不在默认 PATH！绝对路径 `D:\DSH\toolchain\.cargo\bin\cargo.exe`，且**必须设** `RUSTUP_HOME=D:\DSH\toolchain\.rustup`、`CARGO_HOME=D:\DSH\toolchain\.cargo`（否则 rustup 报 no default toolchain）。首次全量编译 ≈ 8 分钟 |
| 长命令会被系统回收 | >90~120s 的前台命令与部分后台进程可能被杀。**模式**：`Start-Process cmd "/c ... > log 2>&1 & echo done > x.exit"` 后轮询；cargo 增量可反复续跑 |
| cmd `%ERRORLEVEL%` 陷阱 | `A & echo %ERRORLEVEL%` 在解析期展开（拿到旧值）——完成标记用脚本自身写文件 |
| PowerShell 管道写文件 | `Get-Content -Raw | Set-Content` 会损坏 UTF-8 中文源码（market.ts 曾被写花后重写恢复）——**一律用 Edit/Write 工具**改文件 |
| gitignore 编码 | dsh-desktop/.gitignore 是 GBK 历史编码；追加条目用纯 ASCII 行或 Edit 工具 |
| 契约测试路径是拆开的 | `'lib','desktop','companion-sync.js'` 整串 grep 搜不到！**按裸文件名碎片搜**（曾因此漏掉第五个测试读者 retired-market-migration） |
| 注册表脏值事故 | HKCU Uninstall InstallLocation 曾含内嵌引号 → 备份 CMD 解析炸（255）。已修 + 防御；若复现查该键 |
| TS7 注意 | `moduleResolution:"node10"` 已移除——CJS 直接省略该选项；CJS 直译导入用 `import path = require('node:path')`（避免 importStar 样板） |
| 契约测试锚点 | companion-sync 的 `const COMPANION_PLUGINS`/`PLUGIN_UPDATE_SOURCES` 与 RETIRED 数组字面量 `= [` 是测试 indexOf 锚点——**勿加会破坏锚点的内联注解**（RETIRED 上已有注释警示） |
| 数据目录 | 验证时 `DSH_HOME` 指向临时目录；真实启动验证用 CDP 法（HANDOVER.md §6） |
| tauri run 参数 | 子命令参数要 `cargo run -- --bridge-test`（双横线分隔，否则 cargo 吃掉参数） |

5. **GUI 冒烟**：真实加载 → CDP/WebView2 断言桥 → UI 退出零孤儿

## 6. 踩坑教训（新增 8 条，历史 6 条见 HANDOVER.md §7）

9. **长命令被系统回收**：后台化 + 轮询 + cargo 增量重试（见 §3）
10. **cmd 变量展开时机**：`& echo %ERRORLEVEL%` 拿旧值；完成标记让脚本自己写文件
11. **PS 管道重写源码文件会坏编码**：只用 Edit/Write 工具改代码
12. **契约测试路径拆串搜索**：按裸文件名 grep，勿信整串路径匹配
13. **TS 注解破坏文本锚点**：被 indexOf 断言的声明保持原字面形态（RETIRED_BUILTIN_PLUGINS 案例）
14. **TS7 移除 node10 解析**：省略 moduleResolution 即可；@types/node 锁 24.x
15. **注册表脏值可炸批处理解析**：用户机器同样可能中招，防御代码已在 client-updater.js（剥引号）
16. **cargo run 参数要 `--` 分隔**；Rust 出站统一走单写任务（SplitSink 不可克隆）
