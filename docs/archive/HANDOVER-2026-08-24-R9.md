## 1. 吸收内容（对应规划四阶段）

### 1.1 插件进程隔离体系（Phase 2，核心价值）

- `shared/protocol.ts`：单点类型源（Extension 档案/状态机/RPC 帧协议，运行时零依赖）；
- `lib/supervisor/`：registry（`<DSH_HOME>/extensions/registry.json` 原子写）、
  state-machine（installed→…→quarantined，阈值 3、30s×2ⁿ 退避、稳定 60s 清零）、
  installer（staging→SHA-256→原子切换→回滚，绝不触碰 Core Profile）、
  permissions（deny-by-default：net/fs/shell/env）、incidents（50 条/插件）；
- `lib/extension-host/`：rpc（长度前缀帧 + 4MiB 上限）、manager（init 握手 15s
  前不加载插件代码、心跳 10s/5s 判死、并行拉起、防重启风暴）、job-fence
  （Rust Job Object 围栏，缺失降级 taskkill）、sdk（registerTool/on/provideContext/
  settings/权限门）、bridge-server（回环 HTTP，node:http 非 fetch）；
- `host-bootstrap.ts`（每插件进程入口）；`assets/sdk-plugins/sample-sdk-plugin`；
- `assets/plugins/dsh-eac-core-bridge`（受信组件，已注册进 COMPANION_PLUGINS，
  默认启用；env 由 sidecar 注入）；
- `assets/recovery-center.html` + preload（Tauri WS 客户端）；
- **Tauri 适配**：L2 sidecar 为 Supervisor（server.ts 挂载 + boot 集成 +
  rc.action/rc.close 方法 + 恢复模式短路）；Rust 壳新增恢复中心窗口/托盘项/
  relaunch-safe-mode/DSH_DESKTOP_RECOVERY 直开。

### 1.2 全面 TS 化（Phase 0 + 1 + 4a）

- tsconfig 对齐重构版严格度（保留 commonjs）：noUncheckedIndexedAccess /
  exactOptionalPropertyTypes / noImplicitOverride（刻意不启 erasableSyntaxOnly，
  项目 Wave 0 用 import-equals 直译；测试 import 编译产物无需 type-stripping）；
- 根模块全部转 .ts：logger / updater / client-updater / plugin-guard /
  plugin-updater / rescue-agent / renderer-recovery / preload / sidecar ping /
  发布链 6 脚本（tsc 就地产出、行为零变更；boot-smoke 佐证）；
- main.js 登记豁免（冻结回退链，不进发布产物）；
- 测试套件 77×.mjs → .ts（纯 ESM 语法机械迁移），test-runner 默认
  `test/*.test.ts`（Node ≥24 直跑）；
- 发布链脚本前置 build（predist/prepack/postinstall/fetch-*）。

### 1.3 Rust 原生 + 性能（Phase 3）

- `native/supervisor`（Job Object 围栏：KILL_ON_JOB_CLOSE/内存/CPU/流式 SHA-256）
  + `native/snapshot`（内容寻址快照引擎），Cargo.lock 入库，index.node 预编译 +
  build:native 可重建；
- `scripts/build-native.ts`：lld-link 复制到 `%TEMP%/dsh-lld-link`（无空格路径，
  规避 RUSTFLAGS 按空白截断含空格项目路径）；npm scripts
  build:native/test:native/clippy:native；predist/prepack 强制 copy .node；
  stage-resources 纳入 vnext lib 模块 + native 产物；
- 性能：plugin-copy 收编（戳记 {v,f,b}→{v,f,b,h} FNV-1a 滚动哈希 + 单遍走树 +
  源戳缓存 + 目标完整性判定缓存，companion-copy-integrity 契约保留）；
  guard 静态扫描 verdictCache（2 万条上限）。

## 2. 架构映射速查（重构版 → 本地）

| 重构版（Electron） | 本地（Tauri） |
|---|---|
| Electron main = Supervisor | L2 sidecar（server.ts） |
| BrowserWindow 恢复中心 | Rust WebviewWindow + http_serve /recovery-center |
| ipcMain rc:action | WS 桥 → sidecar `rc.action` → handleRcAction |
| app.relaunch（safe-mode env） | safe-mode.json + shell.relaunch-safe-mode 通知 |
| lib/proc.ts nodeExe | lib/desktop/runtime-paths nodeExe |
| lib/state.ts（全量 AppState） | lib/state.ts（隔离体系最小字段） |
| lib/log.ts（desktop.log 双通道） | lib/log.ts（可注入 sink = sidecar ctx.log） |

## 3. 本地化适配决策（与重构版的差异）

1. 恢复中心动作**分发在 sidecar**（无 Electron IPC）；窗口在 Rust；
2. 安全模式用本地 `<home>/guard/safe-mode.json` 语义（非 env-relaunch）；
3. plugin-copy 保留目标完整性判定（companion-copy-integrity 契约），加判定缓存；
4. 测试 recovery-integration.test.ts 是重构版源码断言（lib/boot.ts 等本地没有），
   删除；recovery-center.test.ts 重写为 Tauri 架构断言；
5. build-native 的 lld-link 落 `%TEMP%`（路径空格规避）。
