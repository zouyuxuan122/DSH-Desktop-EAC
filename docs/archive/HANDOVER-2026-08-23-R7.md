## 1. 内核升级（rc.7 → rc.2）要点

3. **浏览器模块双源**：前端 dist 内置种子表（react 家族/cordis/**ui-slots**/**ui-primitives**）+ /plugins graph。ui-slots/ui-primitives 不在应用 npm 树里是**正常现象**，别当缺依赖补。
4. **宿主闭包缺口**：rc.2 的 llm-pi-ai 挂载即调 ctx.authorization → `@deepseek-ai/dsh-authorization` 已加直依赖。全树 peer 扫描仅此一个缺口。
5. **锚点补丁全兼容**：session-manage 5/5（HOST_MAP 双候选 rc.7/rc.8+）；patch-deps 两正则命中；tool-bash 折叠 vendored 修复 rc.7≡rc.2 直接沿用；subprocess-local 超时 vendored 修复上游已原生实现，**已废弃删除**。

## 3. 破案记录（下个模型必读）

1. **Tauri NSIS 记忆安装目录的位置**：`HKCU\Software\deepseek\<productName>\(default)`——不在 Uninstall 键！清理实验环境时漏删它会导致新安装继承旧目录（本轮一度装进 `D:\DeepSeek Harness EAC重构版正式版`）。
2. **NSIS exit 2 确定性失败 = C 盘耗尽**：NSIS 经 %TEMP%（C:）中转 ~500MB；本轮 C 盘被 **25 个 PyInstaller _MEI 泄漏目录**（每个 120MB，大肥鱼桌宠 helper 每次启动泄漏）吃到只剩 265MB，安装必败。清理后 3.0GB 恢复，安装 27s 完成。用户机器 C 盘紧张时同样会踩——**建议后续在安装器里加磁盘空间预检**。
3. **electron-builder 卸载器 `_?=` 语义**会派生分离副本在 ExecWait 返回后继续收尾（含删键）——与卸载键同名的场景存在理论竞态；本轮实测未复现（键删除发生在新键写入前），若未来升级链出现"装完键消失"优先查这里。
4. **copyText 冒烟失败≠回归**：本机跑着网易UU远程/GameViewer（远程剪贴板同步常驻持锁）。R6 两轮全过，本轮加了 3×300ms 重试仍败——常驻占用重试治不了，正常用户桌面无此软件。验证剪贴板功能请关远程软件或手动。
5. **4.4.1 的 Setup 在本机只铺文件不写键**（原因未明，疑与历史卸载器异步清键竞态）；升级测试因此改为手工构造真实用户态键（键名=productName，UninstallString 带整串引号）。
6. **npm 版本对比**：update-smoke 的 mock 源已随版本走（5.1.0 → mock 5.1.1）；改版本号时记得同步。
