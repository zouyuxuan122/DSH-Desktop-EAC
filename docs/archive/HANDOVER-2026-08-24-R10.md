## 4. 架构地图（接手必读）

### 4.1 隔离体系落位（ADR 0003）

```
L1 Rust 壳（tauri-shell/src/main.rs）
  ├─ 恢复中心窗口：open_recovery_center_window（WebviewWindow → http://127.0.0.1:19873/recovery-center）
  ├─ 托盘「恢复中心…」；DSH_DESKTOP_RECOVERY=1 直开；shell.relaunch-safe-mode → env + app.restart()
  └─ http_serve /recovery-center → recovery_center_page()（注入 recovery-center-preload.js → window.rc）
L2 Node sidecar（tauri-shell/sidecar/server.ts）
  ├─ Supervisor：vnextState.initVNextState / vnextLog.setLogSink / recoveryCenter.init
  ├─ boot.start：archivePluginProfiles → ensureBundledSdkPlugins → [恢复模式短路] → Core Bridge 端点
  │    （env DSH_EAC_BRIDGE_URL/TOKEN 注入 dsh web）→ startAndWait → startEnabledExtensionHosts
  ├─ rc.action / rc.close 方法 → lib/recovery-center/register.ts handleRcAction
  └─ shutdown → shutdownExtensionHosts（树杀全部 Host）
L3 dsh web
  ├─ 39 个 cordis 插件（同进程，零破坏，legacy-cordis 建档不拉起）
  └─ 受信 dsh-eac-core-bridge（COMPANION_PLUGINS 默认启用，回环调用 Supervisor）
扩展宿主：<DSH_HOME>/extensions/{registry.json, <id>/{package,data,logs}, .staging, .rollback, .trash}
```

## 5. 关键适配决策与踩坑（接手必读，勿重蹈）

1. **tsconfig 刻意不启 erasableSyntaxOnly**：项目 Wave 0 约定 `import x = require()` 直译
   （emit 与手写 require 逐字节一致）；测试 import 编译产物 .js，无需 type-stripping app 源码。
2. **main.js 冻结不转**（豁免登记于 HANDOVER-TS-MIGRATION §3.5）：R8 红线，不进发布产物。
3. **恢复中心动作在 sidecar 分发**（无 Electron IPC）；窗口在 Rust。重构版的
   recovery-integration.test.ts 是重构版源码断言（lib/boot.ts 等本地没有）→ 已删；
   recovery-center.test.ts 重写为 Tauri 架构断言。
4. **安全模式用本地语义**：`<home>/guard/safe-mode.json` + companion-sync safeModeActive
   （非重构版 env-relaunch）；恢复中心 safe-mode 动作 = 快照→safeModePatch→写文件→请求 Rust relaunch。
5. **plugin-copy 保留目标完整性判定**（companion-copy-integrity 契约：戳记残留但文件缺失→重拷），
   加进程内判定缓存（dest mtime 失效）——不要退回重构版的无判定版本。
6. **lld-link 复制到 `%TEMP%/dsh-lld-link`**：项目路径含空格（`DeepSeek Harness\dsh max`），
   RUSTFLAGS 引号方案不可靠；cargo 相关一律走 build-native.js，不要裸跑 cargo build。
7. **node_modules 遗留损坏教训**：`@deepseek-ai/dsh-subprocess-local` 曾缺 lib/index.js
   （疑似 8-23 被删）导致 boot-smoke 失败；先 `require()` 探活再判断回归。
8. **gui-smoke 环境敏感项**：copyText 依赖系统剪贴板（被其他进程占开时 Set-Clipboard 失败，
   sidecar 注释已说明）；win.close 退出页依赖 settings.exitAction=ask（残留 quit 会让测试级联失败）——
   跑 gui-smoke 前确认 `%APPDATA%/Deepseek Harness EAC/settings.json` 的 exitAction 为 ask。
9. **Electron 回退链（electron-builder.yml/main.js）冻结**：未加 vnext 文件（main.js 不加载它们）；
   `bundled-files` 契约测试未动。发布只走 Tauri。
