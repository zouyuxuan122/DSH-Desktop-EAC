## 1. 用户报告的三类问题与根因

### 1.1 上下文自动压缩频繁触发 → 质量劣化（最严重）
- 根因：`assets/plugins/dsh-compact/lib/engine.js`（旧版）在 `session/event` 把任何
  `turn/end` 输出截断（`reason.kind ∈ {max-tokens, max_tokens, length}`）标记为 overflow；
  下一个 `agent/pre-step` 无条件走 `context-overflow` 强制压缩。内核
  `@deepseek-ai/dsh-compaction-basic` 的 overflow 分支**保留预算为 0**
  （`selectCompactableRange(..., 0)`，不查阈值）→ 整段历史被换成一个 `<compacted-summary>`。
- 触发面：pi-ai 路由（`oc/*` 免费模型）输出常被 `length` 截断 → **每轮对话首步就烧历史**，
  摘要连摘要 → 模型在摘要上作答、幻觉、质量极差。且无冷却：pre-step 内可 forced+pressure
  双压；压缩后仍超阈值时内核 throw 被吞，下一 pre-step 复压。
- 辅助放大器（不做内核改动，见 §5 遗留）：router 路线 contextWindow 落到 pi-ai 默认 262144
  （非 1M），阈值 ≈ 0.75×262144，比预期早触发。

### 1.2 更新（全新/覆盖安装皆现）对话栏"疯狂抽搐"
- 根因：`dsh-better-sidebar`（默认启用）向 `#root` 注入
  `margin-right: var(--dsh-sidebar-width)` 过渡 0.3s，并向中栏
  `#root > div[data-slot="root"] > div > div:nth-child(2)` 注入
  `margin-bottom: var(--dsh-sidebar-height)` 过渡 0.3s；变量在每次会话切换/面板开合/窄窗口
  迁移时重写 → 整条中栏（含输入栏）以 0.3s 动画整体位移，其
  `ResizeObserver(measureCenter)` 动画期间逐帧回读渲染 → 视觉持续抖动。
- 插件自带 `body[data-dsh-sidebar-dragging]` 只覆盖拖拽；`prefers-reduced-motion` 兜底形同虚设。

### 1.3 新建对话对话框上下截断 + 模型选择框上方被遮挡
- hero 截断：`.wSkVaW_root[data-phase=hero] .wSkVaW_scrollBody{justify-content:center}`
  + `.pXSMma_root{height:100%}` —— 内容高于视口时 flex 居中溢出，顶部不可滚动到达，
  被 `overflow:hidden` 链（`.pI_x6G_centerCol`、scrollBody）与壳层 36px 玻璃栏切掉。
- 模型菜单遮挡：`._7KE1Ra_menu` absolute 向上展开（`bottom:calc(100%+8px)`，最高 360px），
  z-index 仅 20 且在 z-index:7 的 sticky composerSeat 内；矮窗口/hero 居中位时菜单顶部
  捅出滚动容器与视口（实测顶到 -55px），被玻璃栏与高 z 覆盖物（prompt-optimizer 5000、
  navbar 950）盖住。

## 2. 修复内容（全部为仓库自持层；不碰 @deepseek-ai/* 内核与第三方插件 bundle）

### 2.1 压缩（`dsh-desktop/assets/plugins/dsh-compact/lib/engine.js`）
- **删除"输出截断 → 强制 retain-0 全量压缩"分支**：pre-step 统一走 `pressure` 触发
  （thresholdRatio × contextWindow 阈值 + retainRatio 预算），低于阈值不压缩。
- **自动压缩冷却**：`lastCompaction` WeakMap（按 agent）记 `{at, generation}`；
  仅当 `surface.replaceGeneration` 较上次压缩增长 且 距上次 ≥ 15s 才允许再次自动压缩
  —— 阻断同一步双压、跨轮复压。导出纯函数 `compactionGapOk` 便于测试；
  `registerAutomaticCompaction(ctx, engine, cfg)` 新增 `cfg={now,minGapMs}` 可注入时钟。
- 真实溢出恢复（`agent/request-error` CONTEXT_WINDOW_EXCEEDED / max-tokens / length）
  不受冷却约束，行为不变（保留 #54 防"继续"堆上下文死循环的本意）。
- 测试：`test/dsh-compact-output-overflow.test.ts` 尾部重写为新语义 + 新增 4 项
  （截断不强制压缩 / 超阈值恰一次 pressure / 冷却抑制同表面复压 / 新代际+冷却后可再压 /
  溢出恢复绕过冷却）；`test/dsh-compact-engine.test.ts` 原 request-error 用例不变。

### 2.2 UI 垫片（`tauri-shell/sidecar/bridge.ts` → tsc 就地重生成 bridge.js，
  `main.rs:48` include_str! 编译期嵌入 → 必须整体重打包）
- `injectUiPatchCss()`（主窗与浮窗共用，`html[data-dsh-title-bar-height]` 前缀，
  与 issue #217 同款桥内通道）：
  - `#root` / 中栏 `transition:none!important` —— 抽搐根治（布局让位保留，瞬时到位）；
  - hero 阶段 `justify-content:flex-start!important` + 子项 `margin-block:auto!important`
    —— 内容放得下居中、放不下从顶排布可滚动（顶部不再被裁）；
  - `._7KE1Ra_menu{z-index:5100!important}` —— 压过同排 prompt-optimizer(5000)/navbar(950)。
- `initPopupRescue()`（JS shim）：MutationObserver 监听 `._7KE1Ra_menu`；
  菜单顶进入玻璃栏区（top<40px）即加 `dsh-popup-flip` 翻转向下
  （`top:calc(100%+8px);bottom:auto`）并按触发钮下方可用空间收缩 maxHeight；
  关闭/空间充足时还原。菜单存续期间 200ms 低频轮询 + resize 重探。

### 2.3 版本
- 版本**保持 5.1.0**（`dsh-desktop/package.json` 与 `tauri-shell/tauri.conf.json` 不引新版本号；
  发布复用既有 `v5.1.0` release，用 `gh release upload --clobber` 替换产物，
  避免 client-updater 被新版本号带偏）。

## 5. 遗留与建议
- pi-ai 路由 contextWindow 262144 放大器：不改内核；建议在
  `~/.dsh/settings.yaml` 的 router 模型条目显式配置 `contextWindow: 1000000`。
- dsh-compact 的 `maxTokens: 8192 / compactionRetries: 0` 仍硬编码在
  `policy.js toBasicResolvedConfig`，无 UI 暴露（保持现状）。
- 第三方插件（better-sidebar/prompt-optimizer/navbar 等）一律不改 bundle，
  只经 bridge 垫片；后续内核升级若 DOM/CSS 类名变动，垫片选择器需回归。
- 本轮 commit 仅本地；push 需用户明确授权。
