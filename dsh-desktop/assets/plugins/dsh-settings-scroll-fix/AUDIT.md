# Source Audit

审计日期：2026-08-23

## 原脚本问题

1. **高风险：YAML 注册块缩进错误。** `id` 与 `name` 没有嵌套在 `insert` 数组内，可能导致 profile 无法解析或插件不被挂载。
2. **高风险：选择器绑定旧构建哈希。** `.VOzbGW_options`、`.VOzbGW_navList`、`.VOzbGW_panel` 在 DSHEAC 5.0.0 当前页面资源中不存在，插件即使加载也不会修复滚动。
3. **中风险：强制 panel 为 `overflow: hidden`。** 页面结构变化时可能截断内容，且会阻断浏览器的滚动链。
4. **中风险：模块求值时直接修改 DOM。** 没有显式生命周期边界，热重载或卸载时依赖宿主猜测清理。
5. **中风险：无事件、观察器和状态清理契约。** 后续扩展为脚本逻辑时容易留下重复监听。
6. **低风险：固定 `.bak` 会覆盖上一次备份。** 多次安装无法保留独立恢复点。

## 审计版改进

- 使用正确的 bundle patch 格式。
- 根据设置界面语义和实际 `scrollHeight/clientHeight` 识别滚动区域。
- 不设置外层 panel 的 `overflow: hidden`。
- 所有 DOM 改动都在 `apply()` 内完成并返回 disposer。
- MutationObserver、wheel/resize 监听、样式和标记均可完整清理。
- 无网络请求、无文件读写、无凭据访问、无第三方运行时依赖。

## 剩余风险

- 设置界面的语义文本和 DOM 层级若完全改变，启发式识别可能失效，但不会扩散到未识别为设置页的普通对话区域。
- wheel 兜底会在设置页内阻止默认滚动，仅当已标记区域确实能沿滚轮方向继续滚动时触发。
