# dsh-settings-groups — 设置页「常规」页内高级选项折叠

DSH Desktop 配套插件：打开「设置 → 常规」页面时，低频使用的选项行（按行
标题关键词识别：外观/语言/权限/开发者/实验等）会被收进页面底部一个可折叠
的 **高级选项** 组，默认收起，页面只显示高频的常规行。

- 默认**收起**，未配置时行为一致（展开状态存 `localStorage` 的
  `eac:settings-groups:v1`，重启/更新后保留）。
- 折叠只隐藏行，**不移动任何 DOM 节点**（组头置于行流底部），与
  dsh-settings-nav-custom 同一套重放策略，不干扰官方设置页的 React 渲染。
- 识别不到的选项行永远留在常规区（零误伤）；行标题含
  `外观 / 语言 / 权限 / 开发者 / 实验 / 高级`（含英文对应词）即归入高级组。
- 纯客户端实现（host 半边 no-op），无宿主依赖；在「设置 → 插件 → 管理」
  可随时关闭。
