# Deep Whale Day & Night Theme · 鲸鱼娘昼夜工坊

随 Deepseek Harness EAC 内置分发。启用路径：**设置 → 皮肤 → 鲸鱼娘昼夜工坊**。

## 出处 / Original Source

- 原项目仓库：https://github.com/GGBond2424648901/deep-whale-day-night-theme
- 角色原作：**上善**（Pixiv：https://www.pixiv.net/users/62155430）
- DeepSeek 女仆鲸鱼娘再设计：**zipzip**（Pixiv：https://www.pixiv.net/users/18604994）
- 主题适配与 UI 制作：**Small-tailqwq**
- EAC 内置适配：Deepseek Harness EAC 维护者

## 功能 / Features

- 完整的水晶白昼 / 月潮观测室夜晚场景
- 白昼 24 个上浮气泡、夜晚 24 个漂移星点
- 侧栏 Q 版鲸鱼娘宠物、鲸鱼花边、玻璃面板
- 原生主题按钮切换昼夜，支持 `prefers-reduced-motion`
