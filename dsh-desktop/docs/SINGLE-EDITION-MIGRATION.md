# 单发行版迁移公告（v5.4 起）

> 落实治理手册"第一步"：同一品牌只维护一个桌面发行版。本文档面向用户与
> 协作者，说明三条旧发行线的去向、双形态安装器的行为与数据位置。

## 从三条发行线到一个安装包

| 旧发行线 | 状态 | 去向 |
| --- | --- | --- |
| **EAC 主线**（Tauri，v5.x，`~/.dsh`） | 继续 | 即本安装包的**完整版**，功能不变 |
| **精简版 Lite**（Electron，v4.6-lite，`~/.dsh-v4lite`） | **退役** | 改用本安装包**精简版**（内核 5.x 全量受益） |
| **整合版 AIO**（Tauri，aio-v1.1.0，`.dsh-aio-data`） | **收编** | 其精选插件理念由**精简版**承接（aio-v1 分支封存归档） |
| **Linux 线**（v4.4.0-linux） | 停更（维持现状） | 需要时从主线源码按 std 方案另行构建 |
| **EAC-IDE** | 进维护模式 | 只修阻断缺陷，不再新功能；推荐改装自己的 IDE |

**同一安装器，安装时选择：**

- **完整版** —— 全部内置插件（多智能体 / 手机桥 / 微信桥 / 桌宠 / 浮窗等）。
- **精简版** —— 同一个包、同一内核，仅外围插件**默认停用**：多智能体、
  微信 ClawBot 桥、手机桥、电脑自动化、大肥鱼桌宠、桌宠设置、输入灵动岛、
  侧边临时会话、会话浮窗、消息回退、自定义提示词、提示词优化器、AI 变更审核。
  核心体验（视口/滚动/设置修复、压缩、保护中心、插件急救、余额与峰谷、
  统一市场、视觉识别、Skills/MCP 管理）**全部保留**。

精简版不是阉割版：停用的插件都在包里，随时在「设置 → 插件 → 管理」或
「设置 → 增强功能」一键启用，**无需重装**。安装器的选择只影响全新安装的
默认值；升级安装重新询问，**用户已有的启停选择永远优先，不会被覆盖**。

## 数据与迁移

- 三条线统一回 `~/.dsh`：主线用户无感；Lite 用户首次用完整版数据目录，
  `.dsh-v4lite` 里的旧数据（设置/会话）可手动拷回 `~/.dsh`（4.x→5.x 会话
  格式由内核启动时自动迁移）；AIO 用户同理，从 `.dsh-aio-data` 迁回。
- 便携包默认完整版行为（无安装器，不存在选择页）。

## 给协作者/维护者的实现说明

- 安装形态标记：安装器 POSTINSTALL 写 `$INSTDIR\dsh-desktop\profile.txt`
  （`full`/`lite`；文件缺失或脏值一律按 full 处理，永不阻塞启动）。
- 默认启停变体：`lib/desktop/install-profile.ts`（LITE_DEFAULT_DISABLED），
  由 `companion-sync.ts` 在「写新行」时消费 —— 复用 dsh-pet 的默认禁用语义，
  用户选择优先，符合核心组锁定的约束（terminal 等核心插件不在精简集内）。
- 回归：`test/install-profile.test.ts`（集合合法性 + 标记读取 + 核心组互斥）。
- 发行版描述符：打包时生成 `dsh-desktop/distribution-descriptor.json`
  （[dsh-distribution](https://github.com/T-Auto/dsh-distribution) Draft
  v1alpha1），组件清单来自插件来源台账 `assets/SOURCES.json`。
